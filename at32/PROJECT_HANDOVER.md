## 一、 项目背景与核心架构

* **项目名称**：AT32 极客智能手表 (AT32 Geek Smartwatch)
* **核心微控制器 (MCU)**：雅特力科技 **AT32F421K8T7**
  * **内核架构**：ARM® 32-bit Cortex®-M4，最高主频 **120 MHz**（内置硬件除法器与单周期乘法器）
  * **存储规格**：**64 KB Flash**，**16 KB SRAM**（注意：无硬件单精度 FPU，编译使用 `-mfloat-abi=soft`）
  * **封装形式**：**LQFP-32**（32 脚，0.8mm 引脚间距）
  * **供电电压**：2.4V ~ 3.6V（板载 3.3V LDO 稳压供电）
* **开发环境配置**：
  * **IDE**：VS Code + **Embedded IDE (EIDE)** 插件
  * **编译器工具链**：**xPack GNU Arm Embedded GCC 13.3.1 (x86_64)**（已部署在纯英文路径 `D:\dev\arm-none-eabi-gcc\bin`）
  * **芯片支持包 (DFP)**：`ArteryTek.AT32F421_DFP.2.2.0.pack`（已集成到项目 `.pack/` 目录）
* **工程根目录（纯英文、自包含工程）**：
  `D:\dev\class\at32`（此目录已完全独立，包含所有驱动库和启动文件，可直接编译通过）
* **硬件设计源文件目录**：
  `D:\工作空间\作业\单片机大作业\`（包含立创EDA绘图脚本、网表、BOM、各模块实物图与芯片官方手册）

## 三、 硬件模块与总线协议细节

### 1. I2C 总线挂载设备（SCL: PA9, SDA: PA10）
同一条 I2C 总线上共挂载了 3 款传感器，7 位从机硬件地址均已硬编码且互不冲突：
* **MPU-6050**（六轴姿态陀螺仪 + 加速度计）：
  * I2C 从机地址：`0x68`（AD0 引脚已在硬件上拉低到 GND）
  * 中断通道：`PA1`（`EXTI_Line1`）
* **QMC5883L / GY-273**（三轴磁力计/电子罗盘）：
  * I2C 从机地址：`0x0D`（若为 HMC5883L 原装片则为 `0x1E`）
  * 中断通道：`PB5`（`EXTI_Line5`，DRDY 数据就绪）
* **BMP580**（双排直插 15x10mm 高精度测高与气压计）：
  * I2C 从机地址：`0x46`（SDO 引脚已在硬件上接地；CS 引脚已拉高至 3.3V 强制 I2C 模式）
  * 中断通道：`PB4`（`EXTI_Line4`，气压采样中断）
* **上拉电阻**：主板已预留 R_SCL (10k) 和 R_SDA (10k) 并联至 3.3V。

### 2. SPI 显示屏接口（ST7789 1.3寸 240x240 IPS 彩屏）
* 屏幕为 7-Pin 2.54mm 排母接口（无硬件 CS 引脚，模块内部 CS 恒定接地使能）。
* 信号定义：`SCL -> PA5 (SPI1_SCK)`，`SDA -> PA7 (SPI1_MOSI)`，`RES -> PA4 (GPIO)`，`DC -> PA6 (GPIO)`，`BLK -> PB0 (PWM)`。
* 驱动建议：使用硬件 SPI1 发送数据，像素格式为 RGB565（16位）。

### 3. 音频模拟输入（MAX9814 AGC 麦克风）
* OUT 引脚直连 `PA0`（`ADC1_Channel_0`）。
* 模块已设置默认增益（50dB）与释放比，采集时建议开启 ADC 规则组并通过定时器触发或连续采样。

### 4. 蜂鸣器驱动电路
* 采用 AO3400A N-MOS 低边驱动电路，栅极控制引脚为 `PA8`（`TMR1_CH1`）。
* PA8 具备高级定时器互补与 PWM 功能，可改变频率实现音调发声（蜂鸣器音乐播放器）。

### 5. 蓝牙透传接口（HC-08 6-Pin）
* 连接 `USART2`（波特率默认 9600 或 115200，8-N-1）。
* `PA2 (USART2_TX) -> HC-08 RXD`
* `PA3 (USART2_RX) -> HC-08 TXD`
* `PB1 -> HC-08 STATE`（高电平表示蓝牙已连接移动端 App）

## 四、 历史 Bug 修复记录与硬件踩坑提示

后续大模型在审核硬件或重绘原理图时，请**务必注意以下已识别的重点问题**：

1. **【严重硬件短路历史 Bug（若修改绘图脚本需注意）】**：
   * 原立创EDA生成脚本 `draw_schematic_master.js` 中，J_BMP_L 的 Pin 4（SDA）与 J_BMP_R 的 Pin 4（INT）在横坐标 `x=1025` 发生碰撞重合，导致生成的网表中 `I2C_SDA` 和 `BMP_INT` 短路合并。
   * 若重新跑 EDA 脚本生成原理图，必须确保 J_BMP_R Pin 4 向右走线，避开 `I2C_SDA`。
2. **【LED 限流电阻阻值调整】**：
   * 原 BOM 表中 `R_LED` 误标为 10kΩ，在 3.3V 下绿色 LED 电流仅 50μA 会极其微弱。
   * **请务必使用 1kΩ ~ 2kΩ 贴片电阻**。
3. **【LDO 稳压输出滤波电容】**：
   * CJA1117B-3.3 输出端原标 100nF 偏小，投板与焊接时建议输出端并联一只 **10μF** 陶瓷或钽电容防止轻载振荡。
4. **【Windows 平台 GCC 编译器的中文路径死穴】**：
   * GNU 链接器 `arm-none-eabi-ld.exe` 遇到中文路径时会把字符转成问号 `????` 导致报 `Invalid argument`。
   * **严禁将工程移动回带中文的目录**！主代码工程必须稳定存放在 `D:\dev\class\at32`。

## 六、 下一步开发任务与技术路线（Roadmap for LLM）

接收本项目的下一代大模型应按以下技术步骤分阶段实现智能手表固件：

### 阶段 1：基础外设驱动与调试通道（BSP 初始化）
1. **时钟配置**：确认 `at32f421_clock.c` 中配置系统时钟为 **120MHz**（基于内部 48MHz RC 振荡器 HICK）。
2. **滴答定时器 Delay**：基于 SysTick 实现微秒 (`delay_us`) 和毫秒 (`delay_ms`) 精确延时。
3. **串口调试 Printf**：初始化 `USART2`（PA2/PA3），重定向 `printf` 到串口，便于向电脑或蓝牙串口助手输出调试日志。
4. **按键扫描**：配置 PA11、PA12、PA15 为内部上拉输入，实现消抖检测（支持短按、长按识别）。

### 阶段 2：屏幕驱动与基础图形库（ST7789）
1. 编写 `st7789.c` / `st7789.h`：
   * 初始化 SPI1（PA5, PA7）最高通信速率。
   * 实现复位时序、初始化寄存器序列（Gamma 校准、色彩格式 RGB565、扫描方向控制）。
   * 实现全屏刷色、点绘制、区域矩形填充函数。
2. 移植或编写轻量级字体库（如 ASCII 8x16, 16x24 字体以及基础中文点阵）。
3. 配置 PB0（TMR3_CH3）输出 0~100% 占空比的 PWM 实现屏幕背光渐变控制。

### 阶段 3：传感器数据采集与融合（9轴姿态 + 气压高度）
1. **I2C 驱动实现**：
   * 鉴于 AT32F421 将 I2C1 映射在 PA9/PA10，建议优先实现**高鲁棒性的模拟 GPIO 软件 I2C** 或配置正确的 GPIO MUX 硬件 I2C。
2. **MPU-6050 驱动**：
   * 唤醒传感器（解除 SLEEP 模式），配置量程（加速度 ±4g，陀螺仪 ±2000dps）。
   * 读取 3 轴加速度与 3 轴角速度原始数据。
3. **QMC5883L 驱动**：
   * 配置连续测量模式与过采样率，读取 3 轴地磁原始数据。
4. **BMP580 驱动**：
   * 读取温度补偿参数、获取当前大气压强，根据国际标准气压公式换算为**相对海拔高度**。
5. **姿态解算**：
   * 采用轻量级 **Mahony 或 Madgwick 算法** 融合 9 轴数据，解算出实时的俯仰角（Pitch）、横滚角（Roll）和偏航角（Yaw/电子罗盘方向）。

### 阶段 4：麦克风音频与手势计步业务逻辑
1. **麦克风音频监测**：
   * PA0 采样麦克风音频信号，计算声音分贝值（环境噪音监测）或简易打击声检测（双击亮屏）。
2. **计步算法**：
   * 基于三轴加速度合力向量的峰值检测与动态阈值滤波，实现离线计步器功能。

### 阶段 5：蓝牙通信协议与交互界面（UI）
1. **蓝牙数据同步**：
   * 定时通过 USART2 将计步数、高度、温度、姿态数据以 JSON 或简易封包格式发送给手机 App。
2. **UI 页面状态机**：
   * 表盘主页（时间、电量、步数、心跳/音量条）。
   * 罗盘与姿态仪页面（3D 姿态示意或指南针指针绘制）。
   * 环境气象站页面（实时海拔、气压与温度曲线）。

## 本次完成

### 1. QMC5883L / QMC5883P 自动识别

现场模块实际是 **QMC5883P**，不是 QMC5883L：

| 型号 | 7 位地址 | ID 寄存器 | ID 值 |
| --- | ---: | ---: | ---: |
| QMC5883L | 0x0D | 0x0D | 0xFF |
| QMC5883P | 0x2C | 0x00 | 0x80 |

QMC5883P 初始化（手册 7.1，正常模式）：

```text
0x29 = 0x06   轴符号
0x0B = 0x08   set/reset on，±8G
0x0A = 0xCD   normal，200Hz，OSR8，DSR8
```

关键坑：**不要先软复位**。之前先写 `0x0B=0x80` 再写配置，读回 `C1=00, C2=00`，
配置被复位清掉；按上面顺序直接写，`C1=CD, C2=08` 正常。

读数：

- 状态寄存器 0x09，DRDY = bit0，OVFL = bit1
- 数据 0x01~0x06，X/Y/Z 小端 16 位
- ±8G：3750 LSB/G，mG = raw × 4 / 15

SWD 实测：`QMC5883P@2C;ID=80;ST=19;C1=CD;C2=08`，磁场
`X=-579mG, Y=-384mG, Z=179mG`，地磁场量级正常。

### 2. 运动页“传感器数值”

路径：**运动 → 传感器数值**。

- 10Hz 刷新
- MPU6050：加速度、陀螺、温度
- QMC5883L/P：三轴磁场
- 底部 `I2C ...` 每秒重扫总线，插拔模块不用重启
- 显示单位压缩为：A = 0.1g，G = 10dps，M = 10mG
- 器件 1 秒读不到显示 `--`

I2C 软件总线从约 600kHz 降到约 200kHz，MPU6050 的 14 字节突发读才稳定。

### 3. 电池与电量角标

- 原理图 P14：`PA1 = BAT_ADC / ADC1_IN1`，R1=R2=100k 分压，实际电压 ×2，C4 100nF
- ADC 时钟从默认 /2（60MHz，超规格）改为 /6（20MHz）
- 4 次平均 + 500ms 缓存；低于 2.0V 视为“未接电池”，显示 `--`
- 右上角常驻电池图标，**不显示百分比**（电压末位抖动没必要）
- 关于页显示 `4.03V` 这种 10mV 精度
- 实测电池约 `4032~4036mV`

### 4. 状态灯

- PB3，高电平点亮
- 设置 → 状态灯：常亮 → 闪烁 → 关闭 → 常亮
- 闪烁周期 500ms 亮 / 500ms 灭
- 底层 `led_set()` / `led_mode_set()` / `led_tick()`

### 5. 熄屏

- 设置 → 熄屏：关 / 30秒 / 1分钟 / 2分钟 / 5分钟，默认关
- 从最后一次按键开始计时，超时关背光（PWM=0），UI 继续运行
- 任意键或抬腕唤醒；唤醒的那一下只亮屏，不触发翻页/进入
- 唤醒后恢复设置里的亮度档位
- 设置和其他项一样，重启后恢复默认（暂无 NVM）

### 6. RAM 角标

旧角标 `R6668` 是 **UI 内存池**已用（池子 6912B），不是整片 RAM。
新角标：

```text
R11/16K C0% 62
```

- `R11/16K` = 整片 SRAM 已用/总量，含 `.data + .bss + 当前栈`
- 静态 RAM：`9936 + 112 = 10048 B`
- 16KB 中扣掉静态和栈，约剩 5KB
- CPU 小数位为放 RAM 总量去掉了，帧率保留

## 已知问题 / 下一步

### 蓝牙 UART 没通

现象：HC-04BLE 能连上，`start_notify` 成功，但收不到任何 UART 数据。

已排除/测试：

| 检查 | 结果 |
| --- | --- |
| 固件 USART2 115200 | 无数据 |
| 固件 USART2 9600 | 无数据 |
| `unpair` 后重连 | 无数据 |
| 复位时 `mon` | 收不到 `boot` |
| SWD 读传感器/寄存器 | 正常，手表在跑 |

优先检查：

1. 模块方向：PA2（手表 TX）→ 模块 RXD，PA3（手表 RX）→ 模块 TXD
2. 模块 TX/RX 焊点/排母接触
3. 用 CH340 有线：CH340 TX→PA3、RX→PA2、GND，115200
4. 确认模块串口波特率是否被改过（HC-08 出厂默认 9600）

### AT24C256（未到货）

- 32KB，I2C，挂 PA9/PA10（地址 0x50~0x57）
- 优先存：设置持久化、指南针校准、步数历史、日志
- I2C 400kHz 约 40KB/s，不适合每帧读字库；字库要读必须加字形缓存
- 两个字体未压缩 24KB，32KB EEPROM 放字库后基本没空间给设置/日志
- 可选压缩：逐字形 RLE（省 5~9KB）或 heatshrink 分块（省 7~12KB）
- 完整消息字库（25.9KB）当前片内放不下，等外部 SPI NOR 或压缩方案
